# Neon Buddy · 成长镜像

**由通用Agent维护的、以发展科学为框架的孩子知识库，以及它的展示与分析界面。**

不是日记平台，不是网页信息录入系统，也不要求家长自己填写心理分析。理论决定信息结构；Agent从获授权材料中提取、归类、关联和分析；网页展示情境、行为、时间脉络、解释依据与未知。Day One只作为配色、留白和阅读感的视觉参考。

## 当前可以做什么

- **成长镜像**：八个发展观察窗口，展示有来源、条件与局限的Agent解释；没有材料或没有有效分析就保留未知，不生成特质分数。
- **持续理解的问题**：围绕具体问题积累支持与反例，回看每轮分析的可比性、材料范围、局限及理解改变原因；允许材料不足或取消，不强迫形成结论。
- **情境与行为**：按明确的环境、熟悉度和行为码关联片段，一键追溯原始来源。计数是材料数，不是行为发生率。
- **成长脉络**：按发生月份与可选的近似月龄并排探索，保留活动、不同来源和后续更正，不画没有依据的“能力提升曲线”。
- **科学知识框架**：六组理论及十张版本化概念卡、观察指引和分析方法卡，明确适用背景、字段与推断边界；通用理论知识不混入孩子资料。
- **Agent协议**：结构化来源、观察、分析；运行时校验、JSON Schema、带修订号的批次CLI、排他锁与原子写入、更正链及依赖删除。
- **实时读库**：Agent通过CLI更新私有文件；网页每10秒读取，不需要重新构建，不从网页写入。
- **独立合成示例**：点“查看合成示例”体验完整分析关系；示例不写进真实库，明确不是实际模型结果。

## 本地运行

Node.js 22.18+（支持直接执行可擦除类型的TypeScript模块）和npm：

```powershell
npm ci
npm start
```

打开 **http://127.0.0.1:52947/**，保持终端运行。`npm start` 构建并运行带只读知识API的本机预览；不是可随意上传到静态托管的儿童数据服务。开发用 `npm run dev`，测试用 `npm test`，类型与生产构建用 `npm run build`。开发与预览共用固定端口，占用时明确失败。

没有真实知识文件时显示空库，不自动填示例，也不联网调用模型。服务初次增加API插件后需要重启；之后Agent更新数据无需重启或重新构建。

## 用你已有的Agent加入材料

给能访问本仓库的Agent以下指令，并提供你授权处理的材料：

> 阅读 AGENTS.md、知识框架与Agent协议，运行kb cards读取科学知识卡。读取当前库与修订，围绕具体问题整理授权材料，保留原文与位置，未知保留null。根据理论、不同情境与反例形成条件性解释，记录读取清单、可比性、反例范围、局限及理解变化原因；材料不足就暂不下结论。生成私有批次，先校验再通过kb apply提交；不直接改current.json，不上传或提交资料到Git。

Agent使用：

```powershell
npm run kb -- show
npm run kb -- cards
npm run kb -- schema --batch
npm run kb -- validate --file knowledge\private\batch.json
npm run kb -- apply --file knowledge\private\batch.json
```

默认数据位置 **`knowledge\private\current.json`**，已被Git忽略。不要把真实材料放进源码、文档、examples或public。CLI不需要页面开着；网页能看到最新文件修订。`expectedRevision`冲突需重读重做，不改个数字强行覆盖。

可用 `NEON_KB_PATH` 指向仓库外的私有文件；CLI和服务需使用一致环境设置。一个知识文件对应一个孩子，不是账号／多租户系统。

## “分析”分别由谁完成

**应用自动完成**来源关系、当前观察筛选、情境与行为分组、时间／近似月龄组织、知识缺口和分析过期检查。

**通用Agent完成**语义提取、跨场景与阶段比较、理论联系、可能解释、反例与局限；结果通过同一协议加入知识库。应用不内置模型供应商，不后台外传资料；这不是把关键词匹配称为心理分析。结构与引用通过校验，也不能证明Agent解释正确。

新修订使旧分析与任务待复核；知识卡升级、专题修订也会使关联分析待复核。Agent重读后追加新版本。来源删除会清理观察、更正链、依赖分析与读取过这些材料的整个任务记录；只删除专题不删除独立原始资料和分析。已复制的文件与外部Agent留存不能由应用撤回。

## 重要边界

- 文件与本机API**未加密、无正式身份授权**。不绑定公网、不转发端口，不直接作为真实儿童数据服务上线。
- 通用Agent可能是外部服务；由使用者决定授权材料范围与服务商留存条件，本应用不能替其担保。
- 没有诊断、人格复制、年龄达标率、未来预测、自动量表或伪装孩子的回复。没有材料不是孩子没有能力。
- `examples` 只有明确标注的合成资料。真实库没有预置儿童数据。
- 旧版浏览器localStorage资料未删除，未自动迁移；旧数据需Agent核对来源和情境后按协议整理。旧页面不再作为应用入口，历史设计在 `docs\history\`。
- 原型早期版本仍保留在本地 `legacy/virtual-child` 分支，不随当前产品加载。

## 主要实现

`src\lib\knowledgeFramework.ts` 定义理论、维度与行为码；`scienceCards.ts` 定义版本化通用知识卡；`knowledge.ts` 定义严格契约、专题、任务、修订和依赖；`knowledgeAnalysis.ts` 提供确定性分析；`KnowledgeExplorer.tsx` 与 `ResearchTopics.tsx` 是只读展示；`scripts\knowledge-cli.mjs` 与 `knowledge-store.mjs` 为Agent写入端；`knowledge-api.mjs` 提供本机读取。完整私有材料不打入前端bundle或dist。
