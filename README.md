# Neon Buddy（React + TypeScript）

面向 2–8 岁儿童家长的真实互动记录工具：每天用 3 分钟记录一次互动，获得温和、可信、可执行的陪伴建议。

> 本产品不提供医疗、心理诊断或治疗建议。数据默认只保存在当前设备，用户可在“设置与隐私”中导出或删除。

## 技术栈

- React 18
- TypeScript 5
- Vite 5

## 已实现能力

- 成长阶段主线（阶段任务、推进进度、里程碑、下一阶段预告）
- 情绪教育主题（识别-接纳-引导）
- 节日与季节主题（28天循环节律、节日小任务、支线记忆提示）
- 家庭关系主题（新增老师/亲属角色、协同交接建议）
- 生活技能主题（阶段目标、自动累计进度、打卡式反馈）
- 世界观剧情主题（阶段支线、照护风格分叉、故事回响、时间线叙事标签、分支进度持久化）
- 家校协同主题（高频触发点、交接摘要卡、双向交接建议、历史面板与快速复制）
- 报告导出中心（成长报告 / 家校交接报告，支持本周/30天/本月/全部快捷范围与手动起止天数导出，支持 Markdown 预览复制下载与结构化 HTML 打印预览）
- 报告模板切换（简版 / 详细版）
- 成长勋章墙（关系、情绪、习惯、家校、记录、周节奏）
- 成长任务系统（勋章建议任务、完成/撤销、进度统计）
- 报告勋章联动（导出范围内新获得勋章自动写入报告）
- 任务奖励反馈（任务完成连击、即时奖励横幅、任务进度条）
- 奖励历史面板（最近奖励记录、单条复制）
- 奖励历史筛选与导出（等级/时间筛选、复制筛选摘要）
- 奖励历史统计卡（等级分布、等级占比、最近7天趋势、连击峰值、连续活跃天数）
- 奖励历史周期对比（近7天/近30天对比上一周期，自动显示上升/回落/持平）
- 统计摘要导出联动（复制筛选摘要时自动附带主力等级、占比、峰值与活跃天数）
- 统计卡一键简报（复制家校奖励简报，自动整合筛选条件、核心统计、周期对比与重点记录）
- 简报模板切换（家长版 / 老师版，一键复制时自动应用对应语气与行动建议）
- 简报 Markdown 复制（按模板生成标题/分节/要点，适配班级群与企业微信转发）
- 简报历史留存（最近20次复制记录，支持回看筛选条件与一键二次复制）
- 简报历史筛选（按对象与格式过滤历史记录，快速定位家长版/老师版与 Markdown 文案）
- 简报差异高亮（与上一条历史自动比对，标出记录数/连击峰值/活跃天数的上升与回落）
- 简报历史批量操作（按筛选导出历史摘要、支持一键清空历史记录）
- 历史恢复机制（误清空后支持最近一次撤销恢复）
- 简报收藏夹（收藏记录置顶展示，且不受“清空历史”影响）
- 收藏夹搜索（按标题/筛选条件关键词快速检索收藏简报）
- 收藏夹导出（按当前搜索结果导出收藏项 Markdown 汇总）
- 收藏夹分组展示（按家长版/老师版与 Markdown/普通简报自动分组）
- 收藏夹批量操作（多选后批量复制与批量移除，支持当前结果一键全选）
- 真实事件输入（类型、强度、文本）
- 快速记录增强（同类型快捷模板、复用最近记录、Ctrl/Cmd+Enter 快捷提交）
- 最近模板置顶（按事件类型记忆最近使用 Top 3，自动置顶显示）
- 输入不断线（描述框默认聚焦、提交后自动回到输入框、Esc 清空、Alt+R 快速复用）
- 分类型草稿箱（切换事件类型自动带回该类型上次草稿，失焦自动保存）
- 一键三段整理（将描述快速整理为“触发-应对-结果”，支持 Alt+S）
- 下一条推荐（根据同类型最近记录生成建议句，支持 Alt+N 一键填入）
- 推荐句学习反馈（保留/不合适/学习改写三键反馈，推荐会持续自适应）
- 推荐反馈历史与撤销（按类型展示最近5条反馈，可撤销上次反馈）
- 推荐来源解释面板（学习样本/历史生成/模板回退来源可视化）
- 推荐来源占比趋势（按类型统计最近20条来源占比，观察模型贴合度）
- 推荐历史来源筛选（按学习样本/历史生成/模板回退一键过滤最近反馈）
- 来源筛选记忆（按事件类型记住最近一次来源筛选）
- 推荐历史关键词筛选（按事件类型记住关键词，快速定位可回填句）
- 关键词筛选快捷键（Alt+K 聚焦筛选输入，Alt+Shift+K 一键清空）
- 推荐历史 Markdown 导出（按当前来源筛选一键复制 Markdown）
- 推荐历史 Markdown 下载（按当前来源筛选一键下载 .md 文件）
- 推荐历史一键回填（从历史记录直接回填到输入框继续编辑）
- 回填模式记忆（按事件类型记住覆盖/追加回填模式）
- 筛选首条快捷回填（一键回填当前筛选首条，支持 Alt+L）
- 回填撤销保护（支持一键撤销最近一次回填，快捷键 Alt+U）
- 追加回填防重复（追加模式遇到末尾重复内容会自动跳过）
- 事件映射成长状态（安全感/亲密度/好奇心/情绪）
- 多角色反馈（家长/祖辈）
- 伦理文案过滤（替换词 + 敏感词拦截）
- 专家卡片（建议与来源）
- 每周总结（趋势、主陪伴者、关键记忆）
- 多账号隔离存储
- 云快照上传/恢复/列表
- 云仓储抽象层（mock-local/http）
- 首次使用引导（孩子称呼、成长阶段、记录视角）
- 今日陪伴闭环（快速记录入口、观察-感受-下一步反馈）
- 设置与隐私中心（数据导出、删除、安全边界与云模式提示）

## 本地启动（由你执行 Node）

1. 安装依赖

```bash
npm install
```

2. 开发模式

```bash
npm run dev
```

3. 构建产物

```bash
npm run build
```

## 目录结构

- `src/App.tsx`：页面与主业务编排

## 云模式切换

在 `src/config/appConfig.ts` 修改：

- `cloud.mode`: `mock-local` 或 `http`
- `cloud.apiBase`: 后端基地址（http 模式必填）

## 说明

- 当前默认 `mock-local` 模式，使用 localStorage 模拟云端。
- 真实后端接口参考 `docs/CLOUD_SYNC_PLAN.md`。
