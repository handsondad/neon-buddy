# 记录输入提效操作手册

本文档用于帮助协作者快速上手“记录真实事件更快更顺手”主线能力。

## 1. 目标与范围

- 目标：降低记录中断、减少重复输入、提升推荐可用性。
- 范围：事件输入区、推荐历史区、回填链路。

## 2. 核心操作流

1. 选择事件类型与照护者视角。
2. 在真实描述中输入原始事件。
3. 使用快捷模板或“同类型最近记录”快速补全。
4. 用“一键三段整理”将内容整理为“触发-应对-结果”。
5. 通过“下一条推荐”获得候选句并执行反馈。
6. 在推荐历史中按来源/关键词筛选并回填。
7. 如误回填，立即撤销。

## 3. 快捷键速查

- Ctrl/Cmd+Enter：提交当前记录。
- Esc：清空当前描述。
- Alt+R：复用同类型最近记录。
- Alt+S：一键三段整理。
- Alt+N：填入下一条推荐。
- Alt+L：回填当前筛选首条推荐历史。
- Alt+U：撤销最近一次回填。
- Alt+K：聚焦推荐历史关键词筛选。
- Alt+Shift+K：清空推荐历史关键词筛选。

## 4. 推荐历史筛选与回填

1. 先选来源筛选：全部/学习样本/历史生成/模板回退。
2. 再输入关键词筛选内容。
3. 点击“回填当前筛选首条”或逐条“回填”。
4. 按回填模式执行：
- 覆盖：直接替换描述区内容。
- 追加：追加到描述区末尾。
5. 追加模式自动防重复：若末尾已是相同内容，将跳过追加并提示。

## 5. 推荐反馈闭环

- 保留推荐：记录“可用”偏好。
- 标记不合适：后续优先避开相同推荐句。
- 学习当前改写：将手工改写纳入学习样本，后续优先命中。
- 撤销反馈：可撤销最近一次非“填入推荐”的反馈动作。

## 6. 状态记忆规则

以下状态按事件类型分别记忆：

- 草稿内容。
- 推荐来源筛选条件。
- 推荐关键词筛选条件。
- 回填模式（覆盖/追加）。

## 7. 常见问题

1. 当前筛选无记录怎么办？
- 先切换“全部来源”并清空关键词，再尝试回填。

2. 为什么没有推荐历史可筛选？
- 需要先执行推荐相关动作（填入、保留、不合适、学习）后才会累积。

3. 回填后内容不对怎么处理？
- 立即按 Alt+U 撤销最近一次回填。

## 8. 验收建议

- 场景 1：切换事件类型后，关键词与来源筛选是否按类型恢复。
- 场景 2：关键词筛选后，导出/下载/回填是否一致遵循同一筛选结果。
- 场景 3：追加回填同一条内容两次，第二次应被自动拦截。
- 场景 4：Alt+K/Alt+Shift+K 在描述输入区可直接触发。
