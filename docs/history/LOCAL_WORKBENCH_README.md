# 历史说明：网页记录与理解工作台（已被Agent知识库架构取代）

以真实经历和心理学观察框架，构建有情境、有阶段变化、可被修正的成长镜像。记录只是素材入口，不是产品终点。

本项目帮助家庭理解孩子，而不是要求每天写日记；不生成心理评分、固定人格标签或孩子的模拟回复。当前分支仅保留**成长镜像**。

旧版完整原型已保留在本地分支 `legacy/virtual-child`（原始提交 `7bd9d6b`），不再随新版打包或提供切换入口。浏览器中已有资料不会因代码清理被删除。切换历史分支前应先妥善保存当前工作，不能强制覆盖。

## 核心使用流程：经历 → 理解 → 支持 → 再核对

1. **成长镜像**：首页以情绪与安全感、关系、自主、兴趣、挑战、日常快乐六个窗口组织了解孩子。展示所选阶段的家庭理解或孩子原话，不用数量生成性格结论；没有资料明确保留未知。
2. **理解工作室**：带着一个具体方面，阅读有来源的心理学观察引导；核对真实情境、行为、原话、不同意见，明确选择依据与反例。可跨主题寻找不同情境。
3. **形成阶段理解**：由家庭填写有条件的描述、另一种解释、待核实问题和可选的支持尝试，注明作者与时间。保存后进入镜像，不冒充AI结论或孩子认可。
4. **阶段对照**：所选阶段与前一个等长时期并排展示同主题原始材料；保留记录者、情境和补充时间，不把资料数量变成进步／退步或支持效果。
5. **回来修订**：从已有理解追加新版本，旧版可回看；引用经历有后来的补充时提示重新核对。删除依据会连带删除依赖理解及后续修订，防止留下失去来源的画像。

心理学内容基于 Harvard 回应式互动、自我决定理论、多报告者评估研究，页面可查看来源。它们是通用知识与产品化提问，不是标准化测评或经验证的儿童分析算法。年龄未采集，不自动推荐年龄常模；婴幼儿研究的适用边界在页面说明。

## 仍保留的素材与数据能力

- 记录真实事件日期、主题、情境、观察、记录者及观察／转述来源。
- 分开保存孩子原话、记录者的待确认理解、可尝试支持和待问问题。
- 按实际日期回看，支持主题、关键词和日期范围筛选；关键词覆盖后补视角。
- 追加孩子视角、成人视角与更正，保留原始叙述与录入时间。
- 孩子视角支持“认可／有不同理解／暂不回答”；选择暂不回答时不保存表达内容，不推测原因。这些状态由录入者提供，不验证身份或同意。
- 本地空间分组、刷新持久化；读写失败、损坏数据和过期写入显式提示。
- JSON完整导出、校验后恢复（替换当前空间）；确认删除事件及其视角、清空当前空间。
- 损坏或版本不受支持的档案可下载原始文本副本；自行保留原始资料并确认后，允许用有效备份恢复，不静默丢弃原资料。
- 检测其他窗口修改／删除当前空间，停用旧列表与引用、阻止过期保存；保留未提交输入供复制或主动放弃，再重新载入。
- 独立版本化档案，不读取或迁移历史原型的剧情、数值或云快照。
- 阶段回顾：默认近30天，可选日期与主题；分别列出观察、原话、视角、待确认理解、支持设想和待问问题，每条可定位原始事件。
- 成长问答（本地检索版）：先明确选择参与检索的经历，再填写关键词和记录类型；只做字面匹配与原文摘录，问题不做自然语言理解。无记录时明确提示，不推断心理、因果或未来。
- 回顾随当前档案实时计算；异步问答绑定提交时的档案、范围和素材选择，任一变化立即使旧结果失效，取消未完成任务，需重新提交。恢复替换、空间切换和清空会重置问答。
- 可替换检索接口与浏览器本地适配器：只接收已选素材，服务只能返回有效引用；原文、作者及来源由档案读取，越界／改写／重复引用会报错，不静默切换服务。不持久化素材选择、派生摘要或问答历史。
- 导出当前回顾为Markdown，包含范围、事件／视角ID、原文、作者和来源说明；备份仍使用JSON。

## 界面与素材工作区

Day One 仅作为浅灰、白色、蓝色与留白的视觉参考，不作为产品功能和信息架构的依据。

- 主导航是成长镜像、理解工作室、阶段对照，原文检索与数据管理为辅助入口。
- “经历与依据”才展示月份列表与日历；其余主界面不再被记录索引占据。
- 素材支持关键词、主题和日期筛选；圆点只表示有记录，不是行为频率。
- 记录列表每页50段，支持翻页；来源跳转会定位到对应分页。详情按需加载，保留仍有未提交补充的表单，避免启动时渲染全部记录。
- “记录一个时刻”和右上角加号打开同一个素材表单，不设日记首页或打卡要求。
- 面板切换与来源跳转保留未提交的记录、补充和理解草稿，**不等于自动保存**。更换理解主题／时间／修订对象前确认放弃理解草稿，普通导航切换不清空。
- 新建记录、补充视角和昵称各有单独的放弃按钮，不删除已保存资料。
- 窄屏使用两行导航，列表和内容单独显示，通过返回箭头打开记录列表。备份、恢复、空间切换和清空统一位于“档案与数据”。

## 本地运行

使用 Node.js 22.18+（支持直接运行可擦除类型的 TypeScript 测试）和 npm。

```powershell
npm ci
npm start
```

打开 **http://127.0.0.1:52947/**。`npm start` 先构建再启动仅监听本机的预览服务，适合当前本地版本试用；使用期间保持终端运行，结束时按 `Ctrl+C`。这是本地静态应用，不是公开部署或生产级儿童数据服务。

开发和检查：

```powershell
npm run dev
npm test
npm run build
npm run preview
```

开发与预览共用固定主机名及端口；不要同时运行。端口占用会明确失败，不自动切到新端口，以免误进入另一份浏览器存储。请先结束自己启动的旧服务，勿终止不明进程。

**始终使用相同地址和浏览器。** `localhost`、`127.0.0.1` 或不同端口是不同存储来源。换地址／浏览器／设备前先导出JSON，再到新位置恢复；应用不会自动迁移。曾在默认开发地址使用过的资料仍留在原来源，需从原地址导出。

技术栈为 React 18、TypeScript 5、Vite 5。测试使用 Node 自带测试运行器，无额外测试依赖。

## 使用本地问答

在“原文检索与导出”设定日期与主题后，展开“选择参与问答检索的经历”，逐条勾选或主动选择本范围全部经历，再填写问题、关键词和记录类型并提交。它是辅助查找工具，不是理解工作室或自然语言成长对话。初始不默认选择任何经历；切换范围会清除选择，新记录不会自动加入。

素材选择只限制下方问答，**不缩小上方阶段回顾或Markdown导出的范围**。检索中可以取消；改变素材或档案后须重新提交，普通面板切换及来源跳转仍保留输入。当前仅运行浏览器内的字面检索，没有语义模型、生成服务或外传请求；素材选择也不等于儿童授权或云端发送许可。

## 备份与故障恢复

在“档案与数据”定期导出完整JSON，包含经历、视角、阶段理解及全部修订。它是当前空间的完整快照，恢复会**替换而非合并**，请先确认目标空间并保留原备份。建议先在一个新空间恢复，核对材料与理解，再处理原空间。Markdown仍只导出原文回顾，不代替完整镜像备份。下载按钮只表示已发起下载，是否保存成功需自行确认。

仍使用版本1，新增可选 `understandings`；原有不含该字段的档案可直接读取，不生成虚构画像。含阶段理解的新备份不要交给旧版应用编辑，旧代码不认识此扩展字段。

若提示档案损坏／版本不支持，应用会停止普通写入。先选择“下载原始资料副本”，保留浏览器读取到的原始文本（可能不是有效JSON，不能冒充已校验备份）；也可以打开另一空间恢复。确需替换当前损坏档案时，勾选已自行保留原资料，再导入有效的版本1 JSON并确认。恢复失败不覆盖原内容。

若提示其他窗口已更改资料，旧记录与检索已停用。先复制需要保留的表单输入，或用单独的放弃按钮清理草稿，再重新载入。重新载入会丢弃当前页面未提交的输入。应用不会自动合并两个窗口的修改。

## 隐私与原型限制

**这是本地原型，不是生产级儿童数据系统，也不是心理评估工具。**

- 不接入AI、不上传数据、不自动采集媒体，不含云适配或模拟养成逻辑。
- 数据保存在浏览器 localStorage，**未加密**；同设备、同浏览器来源的使用者可能访问。
- 本地空间ID只用于分组，不是账号、登录或访问权限。视角作者和来源为使用者填写，未验证身份或同意。
- 浏览器清理、隐私模式或存储额度可能导致不可用；失败不清空表单。定期导出并保护明文备份。
- 备份恢复须为版本1、最多5MB的JSON，最多10000条事件、每条1000个视角；新写入按紧凑JSON的UTF-8字节数限制为5MB，保证可导出恢复。浏览器仍可能有更低限额，超过限额不会覆盖旧资料。已有超大资料仍可下载原始副本。
- 写入前比较上次读取的原始内容，同时监听存储变化、页面恢复与重新获得焦点；拒绝已发现的过期写入。这不是跨窗口事务锁，不支持多人同时编辑，建议每个空间只开一个编辑窗口。
- 删除只影响当前浏览器当前空间，包括事件所属视角、依赖的阶段理解及后续修订；删除理解不删除原始经历。已下载的JSON或Markdown文件须自行删除。
- 未保存表单在切换空间、重新载入或恢复档案前会提醒；筛选和引用跳转不会清空未提交的补充。关闭页面仍应先保存。
- 不支持自动迁移历史原型记录，防止把剧情、模拟回应或推断混成真实经历。
- 阶段回顾使用事件发生日期；后来补充的视角仍归属原事件，同时明确显示补充时间，不把它当成当时已经知道的事实。
- 此处的“问答”不是大模型聊天：问题只用于说明目的；关键词单独填写。未命中不能当作“不存在”，匹配也不证明原因或效果。
