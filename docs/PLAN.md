# 成长镜像实施计划

更新日期：2026-10-29。产品依据：[成长镜像设计](GROWTH_MIRROR_DESIGN.md)。

## 当前主线：科学框架 + Agent知识库 + 只读展示分析

此主线取代下方历史的记录平台／人工理解表单。用户明确要求：理论决定信息的分类和结构；任何通用Agent按约定加入与分析；网页展示理解随年龄和信息增长而更新。不能再用“录入工具做完”作为产品完成。

- [x] 查阅气质、SDT、回应式互动、执行功能、多报告者与发展时间的公开来源，完成科学知识框架、字段映射与推断限制。
- [x] 明确四层：来源原文、情境化观察、显式关系、可撤回的Agent解释；八维窗口为操作化视角而非量表。
- [x] 通用Agent入口、完整协议、JSON Schema、严格校验、带修订号的批次CLI、锁与原子提交。
- [x] 私有文件与前端构建隔离；仅本机只读API，网页每10秒读取，无网页内容／分析录入表单。
- [x] 成长镜像、情境行为关系、月份／近似月龄对照、来源与更正追溯、Agent解释及支持／反例／理论／局限。
- [x] 新修订使旧分析待复核；更正和依赖删除；独立合成示例，不混入私有资料。
- [x] 完成新增契约、CLI、API、分析及实际界面验收后更新结果。

本轮验收：90项自动化测试通过，类型检查与生产构建通过。独立合成知识库通过真实Agent CLI完成入库、追加不同情境与反例、分析修订、观察更正、损坏恢复及获授权来源删除；网页自动读取新修订，旧解释停止作为当前画像，来源与修订链可追溯，依赖删除不影响其他材料。实际开发服务拒绝私有文件直读、网页写入和跨来源读取；仓库内的知识文件路径限制在私有目录。五个视图在320／390／900／1440像素下无横向溢出，日期范围、范围外依据提示、键盘焦点往返与来源抽屉通过核对；没有自动请求外部资源。实际私有库保持空白，合成示例不写入其中。

这验证了“科学框架 → 通用Agent结构化知识与分析 → 只读展示与证据追溯”的技术链路，不等于验证了Agent解释的心理学有效性，更不是已经完成完整数字人格。

后续不以安装特定模型为前置：先用使用者已有Agent通过协议实际整理和分析。模型输出质量评估、可比场景／问题检索、更多有专业审阅的理论内容、正式授权与加密是后续独立工作；不预先新增未获授权的模型调用或云端资料服务。

- [x] 十张版本化通用知识卡，分概念／观察指引／分析方法；明确科学出处、适用背景、字段和限制，CLI与网页共用，独立于私有孩子材料。
- [x] 可追加修订的长期问题专题；保存问题、范围、追踪状态与知识卡版本，而不是固定人格标签。
- [x] 结构化任务记录：读取清单、知识卡版本、情境／时期可比性、反例范围、局限及理解改变原因；允许材料不足或取消，不生成被迫结论。
- [x] 原文UTF-16位置校验与高亮、来源版本ID；旧数据没有位置时明确说明，不猜重复片段坐标。
- [x] 专题／卡片版本变化使依赖分析待复核；删除依据同步删除整个依赖任务摘要，专题删除保留独立资料并明确边界。
- [x] 只读“持续理解的问题”视图，连接问题、知识、每轮解释、反例与原始材料；重读与专题修订保留同一问题的选择。
- [x] 向后兼容旧快照和批次，同步JSON Schema、Agent入口、协议与示例，完成端到端验收。

验收：104项自动化测试通过，类型检查与生产构建通过。在独立合成文件中通过真实CLI完成两轮研究、材料不足、专题三版修订、观察更正、来源及依赖任务删除、专题删除与取消任务；页面自动读取新修订，没有旧任务摘要残留，其他专题保留。专题、展开知识卡、读取清单和原文抽屉在320／390／900／1440像素下无横向溢出，未出现运行时错误或自动外部资源请求。真实私有库未写入合成资料。

这些是可检查的Agent声明和技术引用，不是实际工具执行证明、自动语义验证或心理学有效性认证。下一步内容质量的重点是针对实际授权问题核对卡片适用性和分析质量，而非增加录入表单或交易／测评式分数。
