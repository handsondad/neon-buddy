# 输入提效主线变更日志

> 范围：记录输入效率相关能力，按“用户可感知能力”归档。

## 2026-04 收尾版本

### 1. 输入不断线

- 描述框默认聚焦。
- 提交后自动回到输入框。
- 支持 Esc 清空与 Alt+R 快速复用。

### 2. 草稿与模板

- 分类型草稿箱：切换事件类型自动恢复草稿。
- 最近模板置顶：每种事件类型记忆最近使用 Top 3。

### 3. 推荐与学习

- 下一条推荐：按同类型历史生成候选句。
- 推荐反馈：保留/不合适/学习改写。
- 推荐反馈撤销：支持撤销最近反馈动作。

### 4. 推荐历史增强

- 推荐来源解释与来源占比趋势。
- 来源筛选记忆（按事件类型）。
- 推荐历史 Markdown 复制与下载。

### 5. 回填链路增强

- 推荐历史一键回填。
- 回填模式记忆：覆盖/追加。
- 筛选首条快捷回填（Alt+L）。
- 回填撤销保护（Alt+U）。
- 追加回填防重复：末尾重复自动跳过。

### 6. 关键词筛选收尾

- 推荐历史关键词筛选（按事件类型记忆）。
- 关键词筛选快捷键：
- Alt+K：聚焦关键词输入。
- Alt+Shift+K：清空关键词。
- 来源筛选与关键词筛选统一作用于列表、导出、下载、快捷回填。

## 兼容性说明

- 新增状态字段均通过 `normalizeAppState` 注入默认值。
- 旧账号本地数据可无缝升级，不需要手工迁移。

## 回归建议

1. 切换账号后校验不同账号的数据隔离。
2. 切换事件类型后校验筛选条件记忆。
3. 执行推荐历史导出与下载，确认与页面筛选一致。
4. 验证追加回填重复拦截与回填撤销可用。
