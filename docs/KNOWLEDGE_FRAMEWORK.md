# 成长知识框架 1.0：从发展科学到可分析的知识

更新：2026-10-29。产品以科学框架组织孩子的材料，由通用Agent维护，网页展示和探索；不是把信息录入表单改名为“理解”。

## 1. 理论选择及证据地位

本版采用互补视角，不宣称某一种理论能还原一个孩子。以下公开来源已实际查阅。理论原有研究证据、知识结构的产品化设计、本系统的个体分析，是三个不同的证据层级。

| 理论／证据 | 本框架采用什么 | 因而要保留什么 | 不能推出什么 |
|---|---|---|---|
| Rothbart：气质中的反应性与调节 | 关注接近、退避、情绪反应、注意与调节在不同环境和时间中的表现；气质也在发展 | 发生时间、熟悉度、具体行为、前因、回应、后续；重复片段与反例 | 从一次不加入推断“内向”；从若干叙述得到标准化气质分 |
| 自我决定理论（SDT） | 自主、胜任与联结作为理解支持环境的视角 | 活动、在场者、选择／偏好表达、求助、协助方式、后续 | 拒绝=叛逆，坚持=强动机；从行为码直接计算心理需要 |
| 回应式互动（serve and return） | 保存双向互动，而非只收集孩子一端的行为 | 动作／语言信号、他人回应、后续互动 | 依恋类型、养育质量或脑发育评估。主要婴幼儿研究不能无条件套到所有年龄 |
| 执行功能与自我调节 | 任务要求与支持环境影响日常表现，能力在发展 | 活动、规则变化／先行情境、等待、转换、调整、帮助与后续 | 从分心／停下推断能力缺陷或诊断；自然材料不是能力测试 |
| 多报告者研究 | 同一孩子在不同场景的报告可能不同，应保留报告者与差异 | 来源类型、报告者、原文、场景和时间，不合并成“多数人同意” | 临床评估研究不验证本产品；分歧本身不能证明环境因果 |
| 发展时间／发展监测的边界 | 同一表现要放在发生时的时间背景中；发展监测与正式筛查有区别 | 发生时间与录入时间分离，可选出生年月，事件时近似月龄 | 缺记录=没达到；给出超前／落后比例；自动套用固定阶段或取代专业筛查 |

### 可核查来源

1. [Rothbart：Early Temperament and Psychosocial Development（2019修订）](https://www.child-encyclopedia.com/temperament/according-experts/early-temperament-and-psychosocial-development)：定义、研究方法优缺点、反应性／调节与发展。
2. [Self-Determination Theory：理论概览](https://selfdeterminationtheory.org/theory/)：自主、胜任、联结及支持环境。
3. [Harvard：Serve and Return](https://developingchild.harvard.edu/key-concept/serve-and-return/)：婴幼儿双向回应。
4. [Harvard：Guide to Executive Function](https://developingchild.harvard.edu/resource-guides/guide-executive-function/)：执行功能／自我调节与支持环境。
5. [De Los Reyes 等（2015），The Validity of the Multi-Informant Approach to Assessing Child and Adolescent Mental Health](https://pmc.ncbi.nlm.nih.gov/articles/PMC4486608/)：341项研究的跨报告者综述，适用背景是临床评估。
6. [Zubler 等（2022），Evidence-Informed Milestones for Developmental Surveillance Tools](https://pubmed.ncbi.nlm.nih.gov/35132439/)：发展监测工具的证据背景；本项目没有移植其量表或阈值。

不把这些论文装进孩子知识库，也不把“论文支持一个通用理论”视为“论文支持对这个孩子的具体结论”。理论目录版本随代码维护；修改词表或字段需更新协议和测试。

### 可复用知识单元

`src\lib\scienceCards.ts`将上述依据整理为十张版本化卡片：六张概念卡（反应性与调节、支持需要、回应互动、任务支持、多报告者、发展时间）、一张自然片段观察指引，以及三张分析方法卡（跨情境可比性、替代解释与反例、纵向复核）。`npm run kb -- cards`可供任意Agent读取；网页展示同一来源。

每张卡分别说明摘要、适用发展背景、Agent应核对的问题、关联字段、推断限制与原理论出处。观察／方法卡是本产品根据上述依据制定的操作指引，不冒充论文原有且经验证的评估工具，也没有“专家已认证”状态。卡片不含儿童材料，与私有库分开；专题和任务只引用卡ID与版本。

## 2. 四个知识层

### A. 原始来源 `sources`

使用者授权的叙述、孩子表达、教育者材料或已有材料的文本转录。保存来源类型、报告者、采集时间、完整原文和整理Agent。**来源是某人提供的材料，不自动等于客观事实**；Agent不能伪装成亲眼观察者。

### B. 有情境的观察 `observations`

一份来源可提取多个片段，各自保留可精确回到原文的片段。

- 发生日期 `occurredOn`：只在确切知道某天时填写；“去年秋天”等不确定时间用null，原叙述仍在来源内。不得用录入日期替代。
- 具体行为 `behavior`：必须是原文子串；允许原来源本身带偏差，显示时注明未核实。
- 情境 `context`：环境、熟悉度、活动、在场者、之前发生什么、他人回应、后续经过。
- 孩子表达 `childExpression`：区分来源标为原话、回忆转述、概述；三者都不声称系统独立核实。
- 维度 `domains`：一个片段可以关联多个窗口。行为码 `signals` 每项携带原文证据，不使用人格和诊断词。
- 来源与整理者、录入时间、更正链分开保存。上下文归类是Agent的结构化提取，不是已验证的心理变量。

**为什么不直接记“性格”？** “不肯加入”可能发生在不了解规则、新人群、不喜欢活动、想独处等不同背景。材料必须支持区分这些可能性；框架不能在输入时就把解释写死。

### C. 知识关系：确定性组织

实体关系为：来源包含观察；观察发生于某时间／情境、关联多个发展维度；行为码有原文依据；分析引用支持材料、反例与理论；新观察／分析更正旧版本。

这是逻辑知识图谱，当前采用带引用的JSON存储，不强行引入图数据库。关系可被校验与探索，不依赖文件名字或关键词猜测。

### D. Agent解释 `analyses`

通用Agent读取已授权知识和相关理论后提交：

- 具体问题、条件性解释、适用情境。
- 支持观察ID；主动寻找反例，未找到须说明检索和样本局限，不能说不存在。
- 其他解释、局限、下一步可以了解的问题。
- 理论ID、Agent署名与工具、生成时间、所据知识修订号。
- 可追加修订，不覆盖旧解释；不代表孩子认可，不生成“永久画像”。

应用检查结构、引用、原文子串、日期、依赖与修订，**不具备自动证明心理有效性或检测所有不当结论的能力**。通用Agent的输出仍需核对，不能用结构通过掩盖语义错误。

## 3. 八个展示／观察窗口

这些是本项目的操作化分类，不是统一心理量表。完整词表以 `src\lib\knowledgeFramework.ts` 为准。

| 维度ID | 观察窗口 | 典型材料 | 理论联系 |
|---|---|---|---|
| `regulation` | 情绪与调节 | 感受表达、暂停、求助、恢复活动，以及他人回应 | 气质、回应式互动、自我调节 |
| `relationships` | 关系与互动 | 发起、加入、观察、退出、分享，不同伙伴／报告者 | 多报告者、联结、回应式互动 |
| `agency` | 自主与动机 | 意愿、偏好、选择、求助，活动的发起与协助 | SDT、多报告者 |
| `exploration` | 探索与学习 | 问题、尝试、重复兴趣、换策略与环境支持 | SDT、执行功能、气质 |
| `attention` | 注意与行动组织 | 等待、切换、调整策略，任务和支持背景 | 执行功能、气质 |
| `communication` | 表达与理解 | 语言、动作、声音等可追溯表达及回应 | 回应式互动、多报告者、发展时间 |
| `movement` | 动作与身体体验 | 游戏和日常行动、练习、来源明确的身体感受 | 发展时间、气质；不作运动或医学评估 |
| `wellbeing` | 日常节奏与体验 | 喜欢的普通体验、节奏与变化背景 | 发展时间、气质、回应与联结 |

不要求一次材料涵盖所有维度，不要求家长每日采集，不把“覆盖率”当成长完成度。

## 4. 随年龄增长，结构如何工作

不是先把孩子塞进固定年龄模板。发生时间、情境、来源与表达保持稳定；可获得的信息和研究适用性随发展变化。

- 早期更多保留动作、声音、照料者回应和日常节奏；不会说话不等于没有表达。
- 后续可能增加同伴活动、规则变化、任务策略、本人愿意提供的语言解释；不强迫孩子配合采样。
- 再后来本人可能更愿意参与解释、纠正、拒绝或限制查看；正式身份和授权系统尚未实施，不能把代录当作已获得同意。
- 可选 `birthMonth` 只显示事件时近似月龄，约有一个月误差；缺失就明确未知，不猜生日。
- 比较两个时期时，Agent必须同时比较活动难度、环境、记录者和帮助。前后材料不可比时，应说无法判断，不拟合“心理成长曲线”。

## 5. 分析方法与当前实现

### 应用自动执行

1. 读取最新有效知识库，剔除已被更正的观察以构建当前视图。
2. 按维度、发生时间过滤；未知日期不塞入时间段。
3. 按显式环境／熟悉度分组，列出有原文支持的行为码与关联片段。
4. 按发生月份和近似月龄对照原始材料；保留来源与场景。
5. 展示Agent解释及支持／反例／理论，点回观察与来源全文。
6. 报告缺背景、少来源、缺孩子表达、无日期、分析待复核等**知识缺口**，不评价孩子缺陷。
7. 按具体问题展示专题、每轮任务的读取材料、反例检查、可比性、理解变化原因及历史解释。任务声明不是Agent真实执行或心理有效性的证明。

### 通用Agent承担的语义分析

1. 从授权材料提取情境化观察，不增添未出现的原因、心理状态或原话。
2. 依据问题选取理论，不为了套理论而选择性丢掉反例。
3. 对比相似场景与不同场景、不同来源与不同时间；说明哪些不可比。
4. 区分已有描述、可能机制和因果主张；日常材料通常只能支持描述和待验证假设。
5. 提供多个可能解释和最有价值的缺失信息，提出不强迫参与、不制造测试的后续观察建议。
6. 提交可追溯分析；新材料提交后，旧分析统一转为待复核。Agent基于新库重读并追加新解释。
7. 将问题沉淀为持续专题，按知识卡版本记录分析任务；证据不足时明确记录不足，不强迫生成解释。每轮说明哪些理解保留、缩小适用范围或撤回，以及原因。

不绑定某个模型供应商；“分析Agent”可以就是使用者已经在用的工具。应用不会后台调用模型，也不会将片段检索包装成语义推理。

## 6. 一个完整例子

原始材料：“在新的桌游小组，他问主持人怎么玩……主持人示范了一轮，他随后加入。”

可提取：新情境／公共活动、活动与在场者、询问行为、`asks_help`、回应、后续；关联关系、表达窗口。不可提取：他害怕、社交能力差、已获得安全感等未记录心理状态。

若另有熟悉场景主动邀请、新场景先观察、熟悉场景选择独处，Agent可以提出“参与方式可能与规则理解、活动偏好等情境因素有关”的条件性解释，并保留替代解释与反例。不能直接结论“他从内向变成外向”或“示范导致改善”。

应用的“查看合成示例”展示这一逻辑；示例不是模型推断的真实验证。
